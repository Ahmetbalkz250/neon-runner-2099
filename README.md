# Neon Runner // 2099
A personal, just-for-fun 2D Cyberpunk platformer built in collaboration with an AI agent using Python and Pygame-CE.
All visuals, neon platforms, parallax cityscapes, and particle effects are generated procedurally in code — no external `.png` or `.wav` assets used.
## Features
- **10 Progressive Sectors:** Each sector gets longer and more challenging with moving platforms, timed laser traps, plasma spikes, and patrol drones.
- **Responsive Movement:** Double jump, coyote time, and a neon dash (with afterimage trails) that can destroy drones.
- **Play Anywhere:** Runs both locally and in the browser via WebAssembly (`pygbag`).
## Controls
- **Move:** `A` / `D` or `Left` / `Right` Arrow
- **Double Jump:** `Space` / `W` / `Up` Arrow
- **Dash:** `Shift` (or `K` / `X`)
- **Restart from Sector 1:** `R`
- **Fullscreen (Desktop):** `F11`
